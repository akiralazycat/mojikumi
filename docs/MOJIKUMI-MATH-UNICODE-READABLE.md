# Mojikumi Math Unicode Readable 仕様

Status: Version 1 / Public beta

## 目的

Unicode Readableは、ブログ、メモ、チャットなどへ貼り付けたときの読みやすさを改善する表示・共有用の派生表現である。数式の保存形式、再入力形式、交換形式としては扱わない。

正本は常に`Strict β`とする。Unicode ReadableはStrict βだけから生成し、LaTeX、MathML、読み上げテキストから意味を補完しない。

## 不変条件

1. 分数の`/`を消さない。
2. 分子、分母、引数、作用範囲を示す括弧を消さない。
3. 複合式を推測して上付き・下付き文字へ変換しない。
4. 総和、総乗、積分の上下限および被演算子を再解釈しない。
5. 関数形式と演算子形式を推測で相互変換しない。
6. 未知の識別子、関数、構文はStrict βのまま残す。
7. 変換結果からStrict βへの逆変換可能性は保証しない。

## 許可する変換

許可リストに含まれる、作用範囲が変わらない置換だけを行う。

| Strict β | Unicode Readable | 条件 |
| --- | --- | --- |
| `^0`–`^999…` | `⁰`–`⁹` | 指数全体がASCII数字だけの場合 |
| `_0`–`_999…` | `₀`–`₉` | 添字全体がASCII数字だけの場合 |
| `*` | `×` | Strict β上で乗算記号の場合 |
| `<=`、`>=`、`!=` | `≤`、`≥`、`≠` | 長い演算子から先に置換 |
| `+-` | `±` | 一つの演算子として現れる場合 |
| `->`、`=>`、`<=>` | `→`、`⇒`、`⇔` | 長い演算子から先に置換 |
| `sqrt(...)` | `√(...)` | 引数の括弧を維持 |
| `sum_...`、`prod_...`、`int_...` | `∑_...`、`∏_...`、`∫_...` | 演算子形式の場合だけ |
| `pi`、`infinity`、`oo` | `π`、`∞` | 独立したStrict βトークンの場合 |
| `alpha`、`beta`、`gamma`、`delta`、`theta`、`lambda`、`mu`、`sigma`、`phi`、`omega` | 対応するUnicode文字 | 独立したStrict βトークンの場合。`x_alpha`のように添字マーカーへ続く場合も含む |
| ASCII `-` | 数学用の`−` | 矢印などの長い演算子を置換した後 |

## 行わない変換

- `(a+b)/(c+d)`を`a+b/c+d`へ短縮しない。
- 分数を`½`などの互換文字へ置換しない。
- `x^(n+1)`の括弧やキャレットを省略しない。
- `sin(x+y)`などの関数引数の括弧を省略しない。
- `sum(k,1,n,k)`を推測で組版された総和へ変換しない。
- 行列、集合、論理式などの未知の構造を自然言語化しない。
- 空白だけを用いて作用範囲を表現しない。

## UIでの扱い

- 出力名は`Readable`とする。
- 「Strict βから安全な記号置換だけで生成する表示・共有向けのUnicode表現」と説明する。
- 厳密な再利用にはStrict β、LaTeX、MathMLを案内する。
- Readableのコピー操作は他の出力から独立させる。

## 検証

曖昧性fixtureを公開アダプターとは別に管理する。各fixtureはStrict β入力、期待するReadable出力、保護する意味境界を持つ。

最低限、次を固定する。

- 単純・複合指数
- 単純・入れ子・複合分数
- 根号の作用範囲
- 積分、総和、総乗
- 関数引数
- 行列
- 関係演算子と論理演算子
- 未知の意味関数を変更しないフォールバック

許可リストを増やす場合は、先に曖昧性fixtureを追加し、Strict β上の作用範囲が変わらないことを確認する。
